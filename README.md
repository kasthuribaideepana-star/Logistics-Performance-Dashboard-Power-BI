Logistics Performance Dashboard – Power BI
📌 Project Overview

This project presents an interactive Logistics Performance Dashboard developed using Microsoft Power BI to analyze logistics operations and delivery performance.

The dashboard provides insights into orders, delivery efficiency, customer satisfaction, hub performance, driver performance, and vehicle utilization.

🎯 Project Objectives
Monitor overall logistics performance
Analyze order processing and delivery efficiency
Track On-Time Delivery Rate and CSAT
Evaluate hub performance and capacity
Analyze driver performance and delayed deliveries
Monitor vehicle activity and maintenance
Understand vehicle breakdown patterns
Analyze orders by vehicle type
📊 Key Performance Indicators
Total Orders: 1,130
On-Time Delivery Rate: 81.6%
CSAT: 86.5%
Average Delivery Time: 35.9 hours
Number of Hubs: 6
Number of Drivers: 55
Number of Vehicles: 45
Active Vehicles: 33

These dashboard metrics are based on the February 2024 view shown in the project.

🔍 Dashboard Analysis
1. Hub Analysis

The dashboard analyzes:

Orders processed vs. hub capacity
Hub performance
Hub-wise delivery performance
Time taken by hubs to process orders
Daily processing patterns

The dashboard covers six hubs, including Houston, Dallas Main, Austin, San Antonio, Fort Worth, and El Paso.

2. Driver Analysis

The driver section provides insights into:

Driver performance ratings
Experience vs. performance rating
Delayed delivery rate
Driver-wise delivery activity
Total orders by month

The dashboard includes analysis for 55 drivers and provides individual driver-level details.

3. Vehicle Analysis

The vehicle section focuses on:

Active vs. maintenance vehicles
Delayed delivery rate by vehicle
Vehicle age vs. breakdowns
Orders by vehicle type
Breakdown by vehicle code
Breakdown by vehicle model

The dashboard contains data for 45 vehicles, with 33 active vehicles and 12 vehicles under maintenance.
